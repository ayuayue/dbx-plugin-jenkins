--------------------------------------------------------------------------------
一、功能简介
--------------------------------------------------------------------------------

  在 DBX 内直接管理 Jenkins 控制器，不必再开浏览器：

    · 概览：控制器版本、队列长度、节点与执行器占用
    · 任务：按 Jenkins Views 分组，支持文件夹层级、名称过滤
    · 构建：构建列表、构建详情、变更集（提交人 / 时间 / 文件数）
    · 控制台：日志行号、级别着色、ANSI 解析、关键字搜索、仅看问题、全屏
    · 阶段视图：Pipeline 各阶段状态与耗时
    · 队列 / 节点 / 执行器：排队原因、离线原因、构建进度
    · 写操作：新建、编辑、重命名、删除任务与视图；触发、停止构建；取消排队

  本版本（0.7.5）新增：停止构建与取消排队改为应用内二次确认弹窗，
  不再依赖浏览器原生 confirm（在宿主窗口内该调用会被忽略，表现为点击无反应）。

--------------------------------------------------------------------------------
二、环境要求
--------------------------------------------------------------------------------

  · DBX 0.6.43 或更高版本（插件清单 engines.dbx 要求）
  · Windows x64
  · 能访问 Jenkins 控制器（HTTP / HTTPS）
  · Jenkins 2.x（开发与端到端验证基于 Jenkins 2.586）

  可选：
  · 创建 Pipeline 任务需 Jenkins 已安装 workflow-job、workflow-cps 插件
  · 阶段视图需 Jenkins 已安装 pipeline-rest-api 插件

四、安装步骤
--------------------------------------------------------------------------------

  1. 打开 DBX，进入「插件中心」，打开右上角「设置」，
     勾选「允许安装未签名开发包」。
     说明：0.7.5 为未签名候选包，未勾选此项安装会被直接拒绝。

  2. 在「插件中心」点击「安装」→「从文件」，
     选择 io.github.nixing178.jenkins-0.7.5-windows-x64.dbxp。

  3. 安装完成后，在「已安装」列表确认插件版本显示为 0.7.5。
     若显示其它版本，说明选错了安装包。

  4. 新建连接：连接类型选择「Jenkins」，按第五节填写参数，
     点击「测试连接」，通过后保存。

  5. 打开工作台「Jenkins 管理台」即可使用。

  提示：插件同时提供「连接提供方」「工作台」「AI 工具（MCP）」三个能力，
        安装后均会出现在插件中心对应分组下。

--------------------------------------------------------------------------------
五、连接配置
--------------------------------------------------------------------------------

  字段              说明
  ---------------   ------------------------------------------------------------
  连接名称          自定义显示名，默认 Jenkins
  协议              HTTPS（默认）或 HTTP（仅限内网）
  IP / 域名         Jenkins 控制器地址，如 ci.example.com
  端口              默认 8080
  上下文路径        部署在子路径时填写，如 /jenkins；根路径留空
  用户名            留空表示匿名只读访问
  API Token         Jenkins「用户设置 → API Token」中生成
  只读模式          默认开启；开启时后端拒绝一切写操作
  跳过 TLS 校验     仅用于自签证书的内网实例
  连接超时（秒）    默认 15

  API Token 生成路径：
    Jenkins 右上角用户名 → 设置（Security）→ API Token → 添加新 Token
    复制后只显示一次，请立即填入连接配置。

  建议：
    · 生产环境使用专用账号 + API Token，不要复用个人管理员令牌
    · 仅浏览时保持「只读模式」开启；需要写操作时再关闭
    · 自签证书优先导入系统信任库，确实无法导入时再勾选「跳过 TLS 校验」

六、升级与卸载
--------------------------------------------------------------------------------

  升级（0.7.4 → 0.7.5）
    直接安装新包覆盖即可。版本号按 semver 递增，DBX 允许升级安装。
    已签名版本不会被未签名包覆盖；反之亦然。

  从旧插件升级（com.anjun.jenkins → io.github.nixing178.jenkins）
    插件 ID 于 0.3.0 变更，DBX 视为两个独立插件：
      1) 先在插件中心卸载旧插件 com.anjun.jenkins
      2) 再安装本插件
      3) 旧插件的 Jenkins 连接不会自动迁移，需在新插件下重新创建

  卸载
    插件中心 → 已安装 → Jenkins 管理台 → 卸载。
    卸载不会修改 Jenkins 服务器上的任何数据。

七、常见问题
--------------------------------------------------------------------------------

  1) 安装时提示不允许安装未签名插件
     解决：插件中心 → 设置 → 勾选「允许安装未签名开发包」后重试。

  2) 启动报错：
     Plugin 'io.github.nixing178.jenkins' initialization failed:
     backend identity 'x' does not match manifest 'y'
     原因：包内后端版本与 manifest 声明不一致（早期 0.2.0 存在此问题）。
     解决：改用 0.7.5 官方候选包；若仍报错，先卸载再重新安装。

  3) 点击「停止」或队列「取消」没有反应
     原因：0.7.4 及更早版本使用浏览器原生确认框，在 DBX 宿主窗口内被忽略，
           导致操作被静默取消。
     解决：升级到 0.7.5，改为应用内确认弹窗。

  4) 界面只读，无法触发 / 停止 / 新建
     原因：连接配置里的「只读模式」处于开启状态（默认开启）。
     解决：编辑连接，关闭只读模式并保存。后端仍会做二次校验。

  5) 连接测试报 404 或提示资源不存在
     原因：上下文路径填写错误。Jenkins 部署在 /jenkins 时必须填写该前缀。
     解决：核对 Jenkins 访问地址中端口之后的部分是否与上下文路径一致。

  6) 写操作返回 403（No valid crumb / 权限不足）
     原因：账号缺少对应权限，或反向代理丢弃了 Cookie。
     解决：确认账号在 Jenkins 中具备 Job 对应权限；
           若使用 Nginx 等反向代理，确保会话 Cookie 能正常透传。

  7) 创建 Pipeline 任务时 Jenkins 返回 500
     原因：实例未安装 workflow-job / workflow-cps 插件。
     解决：在 Jenkins 插件管理中安装后重试；插件已对该错误做收敛提示。

  8) 阶段视图为空
     原因：实例缺少 pipeline-rest-api 插件，或该任务不是 Pipeline 类型。
     解决：安装插件；只有 Pipeline 任务才有阶段数据。

  9) 控制台日志行号与 Jenkins 网页上的行号不一致
     原因：行号是界面缓冲区的显示序号。日志超过 2MB 时头部会被裁剪，
           界面会显示截断提示。
     解决：需要完整日志时，使用控制台面板的「下载」功能。

八、AI / MCP 工具（可选）
--------------------------------------------------------------------------------

  在「插件中心 → 已安装 → 内置 AI 工具」中开启后，AI 可调用以下工具：

    工具名              读写   说明
    ----------------    ----   --------------------------------------------
    list_jobs           只读   列出任务，支持名称过滤
    get_job             只读   任务详情与参数定义
    list_builds         只读   最近构建列表
    get_build           只读   单次构建详情与变更集
    get_console_log     只读   增量控制台日志（按 nextStart 续读）
    list_queue          只读   队列与阻塞原因
    list_nodes          只读   节点状态与执行器
    trigger_build       写     触发构建（宿主逐次确认）
    stop_build          写     停止构建
    cancel_queue_item   写     取消排队项

  只读连接下，三个写工具不会出现在工具列表中；后端仍会二次拦截。
  任务与视图的增删改不通过 MCP 暴露，只能在界面操作。
